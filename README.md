# Calculator

A small client-side calculator built with Vite + React + TypeScript. All
computation runs in the browser — no backend, no network calls, no data storage.

## Develop

```bash
npm install
npm run dev        # local dev server
npm test           # run the test suite
npm run typecheck
npm run build      # production build into dist/
npm run check-leak # verify no source data is bundled
npm run preview    # serve the production build
```
